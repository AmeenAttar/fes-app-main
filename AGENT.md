## 1. Overview

Internal iOS-first mobile app for investigators, researchers, and staff of
the Cleveland FES Center — a research consortium working on functional
electrical stimulation (FES) and neuromodulation.

- Bundle ID: `org.fescenter.app`
- Expo slug: `fes-app`
- Distribution: TestFlight and App Store (internal — no end-user signup)
- iOS-first; Android is configured but not actively tested

## 4. Running Locally (macOS)

Prereqs: Node 20+, pnpm 9+, Postgres 14+, Xcode + iOS Simulator.

```bash
# 1. Install
pnpm install

# 2. Database
createdb fes_app
DATABASE_URL=postgresql://localhost/fes_app pnpm --filter @workspace/db run push

# 3. API server (reads artifacts/api-server/.env automatically)
pnpm --filter @workspace/api-server run dev
#   → http://localhost:8080/api/healthz returns {"status":"ok"}

# 4. Expo app (separate terminal)
EXPO_PUBLIC_DOMAIN=http://localhost:8080 \
  pnpm --filter @workspace/fes-app exec expo start --ios --go
```

`--go` runs the app in Expo Go (fast, no native rebuild). Push notifications
do not work in Expo Go — see Section 9.

Both `artifacts/api-server/.env` and `artifacts/fes-app/.env` are gitignored.
Templates are in `.env.example` in each package.

## 7. API Routes (`/api/*`)

| Method | Path | Source | Notes |
|---|---|---|---|
| GET | `/api/healthz` | `routes/health.ts` | Liveness check |
| GET | `/api/investigators` | `routes/investigators.ts` | Scrapes `${FESCENTER_BASE_URL}/team/investigators/`; cache 10 min |
| GET | `/api/investigators/:slug` | `routes/investigators.ts` | Scrapes individual page; cache 10 min |
| GET | `/api/events` | `routes/events.ts` | Public Google Calendar iCal feed; cache 5 min |
| POST | `/api/push-tokens` | `routes/push.ts` | Upserts an Expo push token |
| DELETE | `/api/push-tokens/:token` | `routes/push.ts` | Removes a token |

CORS allows all origins (acceptable for an internal app; should tighten for
production — see TD-009 in [`plan-files/handover-backlog.md`](./plan-files/handover-backlog.md)).

## 9. Push Notifications

End-to-end:

1. App boots → `lib/push.ts` → `registerForPushNotifications()`
2. Requests OS permission, fetches Expo push token using `extra.eas.projectId`
3. POST `/api/push-tokens` (token cached in AsyncStorage to avoid re-registration)
4. API server scheduler (`src/lib/notifications.ts`) runs every 5 minutes
5. For each event in the iCal feed, sends:
   - "Tomorrow at the FES Center" 18–30h before start
   - "Starting in 1 hour" 50–75min before start
6. `sent_notifications` unique index dedupes per `(event_uid, occurrence_start, kind)`
7. Tokens returning `DeviceNotRegistered` are auto-deleted

Required to actually send pushes:
- `eas init` to populate `app.json` `extra.eas.projectId`
- An EAS development build installed on a real iOS device (Expo Go cannot)
- APNs Auth Key uploaded to EAS (one-time per Apple team)

## 12. URL Migration Checklist

The FES Center website will migrate from `https://fescenter.org/test` to
`https://fescenter.org`. When that happens:

1. Update `FESCENTER_BASE_URL` in `artifacts/api-server/.env` (and the
   production deployment's environment) to `https://fescenter.org`.
2. Restart the api-server.
3. Verify `GET /api/investigators` still returns a non-empty list.
4. (Future) When `app/news.tsx` is built (Task #2), it will go through the
   same `/api/news` proxy route which also reads `FESCENTER_BASE_URL` — no
   client change required.

`fes-app/constants/menu.ts` still has a hardcoded `https://fescenter.org/blog/`
external URL on the News tile. That tile will be replaced by an internal
`/news` screen in Task #2 (see [`plan-files/handover-backlog.md`](./plan-files/handover-backlog.md))
and the hardcoded URL deleted at that time.

The Google Calendar iCal URL in `routes/events.ts` is `calendar.google.com`
and is intentionally NOT derived from `FESCENTER_BASE_URL` — it is a public
Google Calendar feed and is unaffected by the website migration.

## 13. Known Issues & Limitations

Highlights (full list in [`plan-files/handover-backlog.md`](./plan-files/handover-backlog.md)):

- Investigators scraper is regex-based against the website DOM and will
  silently break if the FES Center website restructures (B-002).
- `equipment-inventory.tsx` and `tuesdays.tsx` render placeholders only.
- News tile opens an external browser; will become an internal screen (Task #2).
- Notification scheduler timezone for all-day events is UTC; FES Center is
  America/New_York (timezone bug for all-day reminders).
- No API authentication; not HIPAA-compliant. Do not introduce PHI without a
  full security review (see Decision 7 in [`plan-files/handover-decisions.md`](./plan-files/handover-decisions.md)).
- `eas.json` and `app.json` still contain `REPLACE_WITH_*` placeholders that
  must be filled before any TestFlight or App Store work.

## 15. Pointers for an AI Agent

- Run only the package you're working on; full-workspace `pnpm typecheck`
  will fail on `mockup-sandbox` (pre-existing, unrelated to the app).
  Prefer `pnpm --filter @workspace/fes-app run typecheck` and
  `pnpm --filter @workspace/api-server run typecheck`.
- The Expo dev script in `artifacts/fes-app/package.json` (`scripts.dev`)
  is Replit-specific. Locally use:
  `EXPO_PUBLIC_DOMAIN=http://localhost:8080 pnpm exec expo start --ios --go`.
- Don't change the items listed in "Do Not Change Without Reviewing" in
  [`plan-files/handover-decisions.md`](./plan-files/handover-decisions.md)
  without reading the linked review notes first.
